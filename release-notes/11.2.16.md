Picture settings for plugins: a setting with "type": "image" lets the user pick a gallery picture, and kb.config().photo goes straight into textures: { iTex0: ... } (a photo on a 3D cube, a sprite or an effect).
The picture stays private to that plugin, is shrunk to 2048 px and is deleted with the plugin. An empty texture source is now an empty slot instead of an error.
New example plugin gl_photo.js, and the plugin test tool runs every plugin with and without a chosen picture.
