New: **Lua 5.4** as a third script engine for mods.

Write a mod as a `.lua` file with the plugin manifest in a `--[=[ @plugin { ... } ]=]` comment, then import it like any other mod. It has the same `kb.*` functions, permissions and time limits as JavaScript mods, runs in a sandbox (no files, no `os`, 64 MB of memory) and can run next to JavaScript mods. Example: `hello.lua`.
