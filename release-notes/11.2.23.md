- Pressed key highlight: new slider (Settings > Animations > Key press) that sets how much a pressed key changes color or glows. Turn it to Off and the key keeps its color, the press animation still plays. Works with every theme material and with the plain keys.
- Soft fade between letters, numbers and symbols: new slider (Settings > Animations > Panels). The keys fade in softly in about 0.14 s when the page changes. Off means instant. It follows the animation speed and the panel animations switch.
- Autocorrect memory: undo the same autocorrection with backspace twice and the keyboard stops correcting that word for good. One undo still only pauses it for a while, so a stray backspace does not teach a typo.
- Plugins: `press_highlight` and `page_switch_anim` can be changed from a mod's `settings` block.
