Free · Open source · Android 8+

The keyboard you can mod.

Expressive Keyboard Pro is a customizable Android keyboard with a plugin system. Mods can draw and animate over your keys, and even run full-screen games.

Download APK Get it on Appteka View on GitHub

After installing, enable the keyboard in system settings and select it as your input method.

Made to feel yours

Built with Kotlin, Jetpack Compose and Material 3 Expressive components.

90+ layouts

Plus Chinese and Japanese input and Indic scripts.

8 designs, one tap

Material 3 Expressive, Liquid Glass, Neon, Neumorphism and more, with Material You colors.

Smart typing

Glide typing, word suggestions and autocorrect.

Make it look right

Custom fonts, a photo behind the keys, key size, spacing and one-handed mode.

Panels

Emoji, GIFs, clipboard, translator and voice input.

Private by design

Incognito mode, and learning is off in password fields. Typed text isn’t sent anywhere unless you use the translator or install a mod with both network and text permissions.

Plugins and mods

Write JavaScript mods that add buttons, layouts and themes, draw and animate over the keyboard, press keys and switch layouts on the fly. Landscape full-screen mods can run games such as Dead Signal and Iron World. For safety, a red dot shows while a plugin uses a sensitive permission.

Plugin format and API: PLUGINS.md

Install in 3 steps

  1. Download the APK from GitHub Releases or Appteka.
  2. Open the app and enable the keyboard in system settings.
  3. Select Expressive Keyboard Pro as your input method.
